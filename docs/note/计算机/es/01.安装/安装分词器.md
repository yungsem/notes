# 安装分词器

## 下载分词插件

根据 Elasticsearch 的版本，点击 [这里](https://release.infinilabs.com/analysis-ik/stable/) 下载对应版本的分词器。

## 安装

```shell
# 将插件解压到 ik 目录
unzip elasticsearch-analysis-ik-8.18.0.zip -d ik

# 设置权限
chmod -R 755 ik

# ES 容器使用 uid 1000
chown -R 1000:0 ik
```

修改 docker-compose.yml​ 文件，添加挂载：

```yml
volumes:
  - ./ik:/usr/share/elasticsearch/plugins/ik  # 挂载分词器
```

重启服务。

## 验证是否安装成功
