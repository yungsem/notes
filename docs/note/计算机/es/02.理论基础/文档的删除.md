# 文档的删除

## 按文档 ID 删除

```json
DELETE /employee/_doc/1
```

## 批量删除

```json
POST /_bulk
{ "delete": {"_index": "employee", "_id": "1"}}
{ "delete": {"_index": "employee", "_id": "2"}}
{ "delete": {"_index": "employee", "_id": "3"}}
```

## 按查询结果删除

```json
POST /employee/_delete_by_query
{
    "query": {
        "range": {
            "age": {
                "gte": 20,
                "lte": 26
            }
        }
    }
}
```
