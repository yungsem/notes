# 文档的新增

## 不指定 ID 创建文档

自动生成文档 ID（使用 POST）：

```json
POST /employee/_doc
{
  "name": "张三",
  "sex": 1,
  "age": 25,
  "address": "广州天河公园",
  "remark": "java developer"
}
```

响应结果：

```json
{
  "_index": "employee",
  "_id": "ndY8kZYBY8DxxWecVLcn",
  "_version": 1,
  "result": "created",
  "_shards": {
    "total": 2,
    "successful": 1,
    "failed": 0
  },
  "_seq_no": 0,
  "_primary_term": 1
}
```

## 指定 ID 创建文档

手动指定文档 ID（使用 PUT）：

```json

POST /employee/_doc/2
{
  "name": "李四",
  "sex": 1,
  "age": 28,
  "address": "广州荔湾大厦",
  "remark": "java assistant"
}
```

响应结果：

```json
{
  "_index": "employee",
  "_id": "2",
  "_version": 1,
  "result": "created",
  "_shards": {
    "total": 2,
    "successful": 1,
    "failed": 0
  },
  "_seq_no": 1,
  "_primary_term": 1
}
```
