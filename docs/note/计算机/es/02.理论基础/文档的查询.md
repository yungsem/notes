# 文档的查询

## 准备数据

创建 index ：

```json
PUT /employee
{
    "settings": {
        "number_of_replicas": 1,
        "number_of_shards": 1
    },
    "mappings": {
        "properties": {
            "name": {
                "type": "keyword"
            },
            "sex": {
                "type": "integer"
            },
            "age": {
                "type": "integer"
            },
            "address": {
                "type": "text",
                "analyzer": "ik_max_word",
                "fields": {
                    "keyword": {
                        "type": "keyword"
                    }
                }
            },
            "remark": {
                "type": "text",
                "analyzer": "ik_smart",
                "fields": {
                    "keyword": {
                        "type": "keyword"
                    }
                }
            }
        }
    }
}
```

## 普通查询

### 按文档 ID 查询

```json
GET /employee/_doc/1
```

返回：

```json
{
  "_index": "employee",
  "_id": "1",
  "_version": 1,
  "_seq_no": 0,
  "_primary_term": 1,
  "found": true,
  "_source": {
    "name": "张三",
    "sex": 1,
    "age": 25,
    "address": "广州天河公园",
    "remark": "java developer"
  }
}
```
