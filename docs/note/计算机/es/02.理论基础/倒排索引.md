# 倒排索引

倒排索引是搜索引擎的核心技术。下面使用一个例子来说明什么是倒排索引。

## 提出问题

假如你有一本书，这本书有 3 页，每页的内容如下：

```markdown
第 1 页：我爱机器学习
第 2 页：机器学习需要数学
第 3 页：数学和编程都很重要
```

现在要搜索 `机器学习` 和 `数学` 这两个关键词，怎么做？

## 正排索引做法（传统做法）

从第 1 页开始找，一直到最后一页，返回这两个关键字所在的页。

## 倒排索引做法

先对每一页的内容进行分词处理，提取文档内容中的分词，同时构建出一张 **倒排索引表** ，记录每个分词出现的位置：

|分词|出现的文档（和出现位置）|
| ----- | ----- |
|我|第 1 页 → 位置1|
|爱|第 1 页 → 位置2|
|机器学习|第 1 页 → 位置3，第 2 页 → 位置1|
|需要|第 2 页 → 位置2|
|数学|第 2 页 → 位置3，第 3 页 → 位置1|
|编程|第 3 页 → 位置2|

当搜索 `机器学习` 和 `数学` ​时：

直接查倒排索引表找到：

1. 机器学习 → 第 1 页、第 2 页
2. 数学 → 第 2 页、第 3 页
3. 取交集 → ​第 2 页同时包含两个关键词

整个过程只需毫秒级，无需扫描全部文档。
