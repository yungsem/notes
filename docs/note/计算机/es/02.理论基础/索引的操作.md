# 索引的操作

## 创建索引

PUT /index_name

```json
PUT /student_index

{
    "settings": {
        "number_of_shards": 1,
        "number_of_replicas": 1
    },
    "mappings": {
        "properties": {
            "name": {
                "type": "text"
            },
            "age": {
                "type": "integer"
            },
            "enrolled_date": {
                "type": "date"
            }
        }
    }
}
```

## 删除索引

DELETE /index_name

```json
DELETE /student_index
```

## 修改索引

### 修改 setting

PUT /index_name/_settings

```json
PUT /student_index/_settings
{
    "index": {
        "number_of_replicas": 2
    }
}
```

### 修改 mapping

增加一个字段：

PUT /index_name/_mapping

```json
PUT /student_index/_mapping

{
    "properties": {
        "grade": {
            "type": "integer"
        }
    }
}
```
