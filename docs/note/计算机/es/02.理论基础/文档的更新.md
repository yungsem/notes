# 文档的更新

## 全量更新（覆盖）​​

```json
PUT /employee/_doc/1
{
  "name": "李华"
}
```

## 局部更新​

```json
POST /employee/_update/1
{
  "doc": {
    "age": 33
  }
}
```

## 批量更新

```json
POST /_bulk
{ "update": {"_index": "employee", "_id": "1"}}
{"doc": {"name": "张三1"}}
{ "update": {"_index": "employee", "_id": "2"}}
{"doc": {"name": "李四1"}}
```

## 按查询结果更新

```json
POST /employee/_update_by_query
{
    "query": {
        "term": {
            "name": "张三1"
        }
    },
    "script": {
      "source": "ctx._source.age = 35",
      "lang": "painless"
    }
}
```

## 并发更新

```json
POST /employee/_update/1?if_primary_term=1&if_seq_no=26
{
  "doc": {
    "name": "张三"
  }
}

# 和上一条同时执行，这条会更新失败，因为上一条先执行完毕，seq_no 会自动加 1
POST /employee/_update/1?if_primary_term=1&if_seq_no=26
{
  "doc": {
    "name": "张三2"
  }
}
```
