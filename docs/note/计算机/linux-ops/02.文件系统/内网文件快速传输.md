# 内网文件快速传输

## 接收端

```sh
nc -l 1234 | tar xzf -
```

## 发送端

```sh
tar czf - /path/to/files | nc remote_server 1234
```

## 命令别名

接收端别名设置：

```sh
alias rd='nc -l 1234 | tar xzf -'
```

发送端别名设置：

```sh
sd() {
    # 参数校验
    if [ $# -lt 2 ]; then
        echo "Usage: sd file1 [file2 ...] remote_server [port=1234]"
        return 1
    fi

    # 解析端口和服务器
    local last_arg="${@: -1}"
    if [[ "$last_arg" =~ ^[0-9]+$ ]]; then
        local port="$last_arg"
        local remote_server="${@: -2:1}"
        local files=("${@:1:$(($#-2))}")
    else
        local port="1234"
        local remote_server="$last_arg"
        local files=("${@:1:$(($#-1))}")
    fi

    # 检查文件列表是否为空
    if [ ${#files[@]} -eq 0 ]; then
        echo "Error: No files/directories specified"
        return 1
    fi

    # 执行传输（保留文件结构）
    tar czf - "${files[@]}" | nc "$remote_server" "$port"
}
```

## 别名使用

接收端使用：

```sh
rd
```

发送端使用：

```sh
sd file1 file2 192.168.1.100
```
